Per-run summary tables derived from the deposited batches (https://doi.org/10.5281/zenodo.24039757), used by `scripts/hcis_revision_statistics.py` to reproduce the statistics reported in the HCIS revision (Wilson intervals, Fisher exact tests, Games-Howell contrasts, burn-in counts).
Run: `python scripts/hcis_revision_statistics.py docs/revision_summaries`
These files are derived data. The reference data are the batch archives in the Zenodo deposit; the tag v2.0-hcis-revision (commit 64d6a69) identifies the code that produced them. This branch adds only the summaries and the script.
